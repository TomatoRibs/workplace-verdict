# 同事判刑书

一个本地单文件的解压玩具网页。挑同事的离谱行为，生成带印章的「判刑书」和竖版分享海报。

## 特性
- 单文件 HTML，零依赖，可离线双击打开
- 5 步向导：案发现场 → 犯罪土壤 → 减刑事由 → 被告登记 → 当庭宣判
- 判决模型：10 条罪证映射到 5 大罪名轴，每次组合不同
- 竖版海报：Canvas 手绘，可下载 PNG、复制图片、复制全文、生成分享链接
- 零上传：选项只存在于浏览器，不经过任何服务器

## 使用
直接用浏览器打开 `assets/workplace-verdict.html` 即可。

## 安装为 WorkBuddy 技能
bash scripts/install_local.sh .
